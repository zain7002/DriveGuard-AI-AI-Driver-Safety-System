🧵 Multi-Threaded Concurrency

Webcam capture and AI frame decoding run in a dedicated background worker thread decoupled from the Flask HTTP server. HTTP status polling (`/api/status`) operates asynchronously at 500ms intervals, ensuring zero stuttering on live video feeds.

🛡️ Temporal Smoothing Buffer

A 7-frame sliding window buffer (`deque(maxlen=7)`) applies moving averages over calculated EAR and MAR values. This completely eliminates false alert flicker caused by natural eye blinks (100–300ms) or rapid speech.

🛠️ Windows NMS Architecture Workaround

On Windows systems, PyTorch often throws RuntimeError: operator torchvision::nms does not exist due to missing C++ compiler extensions.

# Routed to pure PyTorch tensor NMS:
from ultralytics.utils.nms import TorchNMS
_tv = types.ModuleType('torchvision')
_tv.ops.nms = TorchNMS.nms
sys.modules['torchvision'] = _tv

✓ Enables 100% full-speed GPU/CPU NMS with zero crashes or C++ binary dependencies.

Novelty & Core Contributions

What Makes DriveGuard AI Novel?

Three key technological breakthroughs solving real-world driver monitoring hurdles.

🔍
1. Context-Aware Mirror Checking
NO FALSE ALARMS FOR SAFE DRIVING

Differentiates between checking side-view mirrors (0.3s–1.2s glance duration) and true off-road distraction (>1.5s). Driver receives an emerald confirmation badge with zero score deduction.

⚡
2. Graduated Threat Escalation
STAGE 0 ➔ STAGE 1 ➔ STAGE 2 MATRIX

Replaces binary buzzers. Stage 0 is focused; Stage 1 uses soft ambient amber perimeter pulses and chimes for yawning; Stage 2 activates crimson flashing strobes and sharp alert buzzers for microsleep or phone usage.

⏱️
3. Rest Break Fatigue Manager
CONTINUOUS VIGILANCE TRACKING

Continuous driving fatigue causes involuntary attention lapses. The dashboard tracks continuous drive time and enforces mandatory rest break advisories after 2 hours of non-stop highway transit.
